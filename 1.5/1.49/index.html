Problem 1

$\dfrac{0}{m + 7}$$=$$0$ⓐ The zero is in the numerator, and $m + 7$ is not $0$ because $m \ne -7$. Zero divided by any nonzero number is $0$.
ⓑ In $\frac{18 - 6c}{0}$ the zero is in the denominator. Division by zero is undefined, so the answer is undefined.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$\dfrac{0}{d - 4}$$=$$0$ⓐ The zero is in the numerator, and $d - 4$ is not $0$ because $d \ne 4$. So the answer is $0$.
ⓑ In $\frac{15 - 4q}{0}$ the zero is in the denominator, so the answer is undefined.
