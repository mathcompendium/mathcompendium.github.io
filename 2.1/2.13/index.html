  2. Solve: $0.10d + 0.05(d - 5) = 2.15$.

Problem 1

$0.25n + 0.05(n + 5)$$=$$2.95$The problem. Each decimal is hundredths, so the LCD is $100$.
$0.25n + 0.05n + 0.25$$=$$2.95$Distribute $0.05$: $0.05 \cdot 5 = 0.25$.
$0.30n + 0.25$$=$$2.95$Combine like terms: $0.25n + 0.05n = 0.30n$.
$\hl{100}(0.30n + 0.25)$$=$$\hl{100}(2.95)$Multiply both sides by $100$.
$30n + 25$$=$$295$Multiplying by $100$ moves each decimal point two places right.
$30n + 25 \hl{{} - 25}$$=$$295 \hl{{} - 25}$To undo adding $25$, subtract $25$ from both sides.
$30n$$=$$270$Simplify.
$\dfrac{30n}{\hl{30}}$$=$$\dfrac{270}{\hl{30}}$Divide both sides by $30$.
$n$$=$$9$Simplify.

Check: put $9$ in for $n$. $0.25(9) + 0.05(14) = 2.25 + 0.70 = 2.95$.

Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$0.10d + 0.05(d - 5)$$=$$2.15$The problem. Each decimal is hundredths, so the LCD is $100$.
$0.10d + 0.05d - 0.25$$=$$2.15$Distribute $0.05$: $0.05 \cdot (-5) = -0.25$.
$0.15d - 0.25$$=$$2.15$Combine like terms: $0.10d + 0.05d = 0.15d$.
$\hl{100}(0.15d - 0.25)$$=$$\hl{100}(2.15)$Multiply both sides by $100$.
$15d - 25$$=$$215$Multiplying by $100$ moves each decimal point two places right.
$15d - 25 \hl{{} + 25}$$=$$215 \hl{{} + 25}$To undo subtracting $25$, add $25$ to both sides.
$15d$$=$$240$Simplify.
$\dfrac{15d}{\hl{15}}$$=$$\dfrac{240}{\hl{15}}$Divide both sides by $15$.
$d$$=$$16$Simplify.

Check: put $16$ in for $d$. $0.10(16) + 0.05(11) = 1.60 + 0.55 = 2.15$.
