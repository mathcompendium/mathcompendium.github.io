Problem 1

$2(m - 4) + 3$$=$$-1$The problem. The right side is already simple.
$2m - 8 + 3$$=$$-1$Distribute the $2$. The $+3$ is outside the parentheses, so it is not multiplied.
$2m - 5$$=$$-1$Combine like terms: $-8 + 3 = -5$.
$2m - 5 \hl{{} + 5}$$=$$-1 \hl{{} + 5}$To undo subtracting $5$, add $5$ to both sides.
$2m$$=$$4$Simplify.
$\dfrac{2m}{\hl{2}}$$=$$\dfrac{4}{\hl{2}}$Divide both sides by $2$.
$m$$=$$2$Simplify.

Check: put $2$ in for $m$. $2(2 - 4) + 3 = 2(-2) + 3 = -1$, which matches the right side.

Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$5(a - 3) + 5$$=$$-10$The problem. The right side is already simple.
$5a - 15 + 5$$=$$-10$Distribute the $5$. The $+5$ outside the parentheses is not multiplied.
$5a - 10$$=$$-10$Combine like terms: $-15 + 5 = -10$.
$5a - 10 \hl{{} + 10}$$=$$-10 \hl{{} + 10}$To undo subtracting $10$, add $10$ to both sides.
$5a$$=$$0$Simplify.
$\dfrac{5a}{\hl{5}}$$=$$\dfrac{0}{\hl{5}}$Divide both sides by $5$.
$a$$=$$0$Zero divided by any nonzero number is $0$. An answer of $0$ is a real solution.

Check: put $0$ in for $a$. $5(0 - 3) + 5 = -15 + 5 = -10$, which matches the right side.
