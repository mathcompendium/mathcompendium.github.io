Your turn: problems like the one in the video
  1. Classify the equation as a conditional equation, an identity, or a contradiction, and then state the solution: $4 + 9(3x - 7) = -42x - 13 + 23(3x - 2)$.
  2. Classify the equation as a conditional equation, an identity, or a contradiction, and then state the solution: $8(1 - 3x) + 15(2x + 7) = 2(x + 50) + 4(x + 3) + 1$.
Show a hint
Distribute and combine like terms on each side. If the variable drops out, look at what is left: true means an identity, false means a contradiction.
Show the answers

  1. identity; all real numbers

  2. identity; all real numbers

Problem 1

$4 + 9(3x - 7)$$=$$-42x - 13 + 23(3x - 2)$The problem. There are parentheses on both sides.
$4 + 27x - 63$$=$$-42x - 13 + 69x - 46$Distribute on both sides.
$27x - 59$$=$$27x - 59$Combine like terms. The two sides are the same.
$27x - 59 \hl{{} - 27x}$$=$$27x - 59 \hl{{} - 27x}$Subtract $27x$ from both sides.
$-59$$=$$-59$The variable drops out, and what is left is true.
$-59 = -59$ is true for every value of $x$, so the equation is an identity. Its solution is all real numbers.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$8(1 - 3x) + 15(2x + 7)$$=$$2(x + 50) + 4(x + 3) + 1$The problem. There are parentheses on both sides.
$8 - 24x + 30x + 105$$=$$2x + 100 + 4x + 12 + 1$Distribute on both sides.
$6x + 113$$=$$6x + 113$Combine like terms. The two sides are the same.
$6x + 113 \hl{{} - 6x}$$=$$6x + 113 \hl{{} - 6x}$Subtract $6x$ from both sides.
$113$$=$$113$The variable drops out, and what is left is true.
$113 = 113$ is true for every value of $x$, so the equation is an identity. Its solution is all real numbers.
