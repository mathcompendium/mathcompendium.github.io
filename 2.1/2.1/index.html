Determine Whether a Value Is a Solution of an Equation

Try It 2.1

Your turn: problems like the one in the video
  1. Determine whether the values are solutions to the equation $9y + 2 = 6y + 3$: ⓐ $y = \frac{4}{3}$ ⓑ $y = \frac{1}{3}$
  2. Determine whether the values are solutions to the equation $4x - 2 = 2x + 1$: ⓐ $x = \frac{3}{2}$ ⓑ $x = -\frac{1}{2}$
Show a hint
Substitute the value for the variable on both sides, then simplify each side. The value is a solution only if the two sides come out equal.
Show the answers

  1. ⓐ no ⓑ yes

  2. ⓐ yes ⓑ no

Show the worked solution

The same steps as the video. Each ▶ button plays the part of the video where that step is explained.

Problem 1

ⓐ Test $y = \frac{4}{3}$
$9\left(\frac{4}{3}\right) + 2$$\overset{?}{=}$$6\left(\frac{4}{3}\right) + 3$Substitute $\frac{4}{3}$ for $y$ on both sides. We don't know yet whether the sides are equal, so the equal sign gets a question mark.
$12 + 2$$\overset{?}{=}$$8 + 3$Multiply. The threes divide out: $9 \cdot \frac{4}{3} = 12$ and $6 \cdot \frac{4}{3} = 8$.
$14$$\ne$$11$The sides are not equal, so $y = \frac{4}{3}$ is not a solution.
ⓑ Test $y = \frac{1}{3}$
$9\left(\frac{1}{3}\right) + 2$$\overset{?}{=}$$6\left(\frac{1}{3}\right) + 3$Substitute $\frac{1}{3}$ for $y$ on both sides.
$3 + 2$$\overset{?}{=}$$2 + 3$Multiply: $9 \cdot \frac{1}{3} = 3$ and $6 \cdot \frac{1}{3} = 2$.
$5$$=$$5$The sides are equal, so $y = \frac{1}{3}$ is a solution.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

ⓐ Test $x = \frac{3}{2}$
$4\left(\frac{3}{2}\right) - 2$$\overset{?}{=}$$2\left(\frac{3}{2}\right) + 1$Substitute $\frac{3}{2}$ for $x$ on both sides.
$6 - 2$$\overset{?}{=}$$3 + 1$Multiply: $4 \cdot \frac{3}{2} = 6$ and $2 \cdot \frac{3}{2} = 3$.
$4$$=$$4$The sides are equal, so $x = \frac{3}{2}$ is a solution.
ⓑ Test $x = -\frac{1}{2}$
$4\left(-\frac{1}{2}\right) - 2$$\overset{?}{=}$$2\left(-\frac{1}{2}\right) + 1$Substitute $-\frac{1}{2}$ for $x$ on both sides.
$-2 - 2$$\overset{?}{=}$$-1 + 1$Multiply: $4 \cdot \left(-\frac{1}{2}\right) = -2$ and $2 \cdot \left(-\frac{1}{2}\right) = -1$.
$-4$$\ne$$0$The sides are not equal, so $x = -\frac{1}{2}$ is not a solution.
