Try It 1.1

Your turn: problems like the one in the video
  1. Is $4{,}962$ divisible by ⓐ $2$? ⓑ $3$? ⓒ $5$? ⓓ $6$? ⓔ $10$?
  2. Is $3{,}765$ divisible by ⓐ $2$? ⓑ $3$? ⓒ $5$? ⓓ $6$? ⓔ $10$?
Show a hint
Use the tests: $2$ needs an even last digit, $3$ needs a digit sum divisible by $3$, $5$ needs a last digit of $0$ or $5$, $6$ needs both $2$ and $3$, and $10$ needs a last digit of $0$.
Show the answers

  1. ⓐ yes ⓑ yes ⓒ no ⓓ yes ⓔ no

    The last digit, $2$, is even, and the digits add to $4 + 9 + 6 + 2 = 21$, which is divisible by $3$.

  2. ⓐ no ⓑ yes ⓒ yes ⓓ no ⓔ no

    The last digit, $5$, is odd, and the digits add to $3 + 7 + 6 + 5 = 21$, which is divisible by $3$.

Show the worked solution

The same steps as the video. Each ▶ button plays the part of the video where that step is explained.

Problem 1

ⓐ For $2$, look at the last digit. It is $2$, which is even, so $4{,}962$ is divisible by $2$.
ⓑ For $3$, add the digits: $4 + 9 + 6 + 2 = 21$. $21 = 3 \cdot 7$ is divisible by $3$, so $4{,}962$ is too.
ⓒ For $5$, the last digit must be $0$ or $5$. It is $2$, so $4{,}962$ is not divisible by $5$.
ⓓ For $6$, the number must pass both the test for $2$ and the test for $3$. It passes both, so it is divisible by $6$.
ⓔ For $10$, the last digit must be $0$. It is $2$, so $4{,}962$ is not divisible by $10$.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

ⓐ The last digit is $5$, which is odd, so $3{,}765$ is not divisible by $2$.
ⓑ Add the digits: $3 + 7 + 6 + 5 = 21$. $21$ is divisible by $3$, so $3{,}765$ is too.
ⓒ The last digit is $5$, so $3{,}765$ is divisible by $5$.
ⓓ It is not divisible by $2$, so it is not divisible by $6$, even though it is divisible by $3$. It has to pass both tests.
ⓔ The last digit is not $0$, so $3{,}765$ is not divisible by $10$.
