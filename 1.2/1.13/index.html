Try It 1.13

Your turn: problems like the one in the video
  1. Simplify: $19 - |11 - 4(3 - 1)|$.
  2. Simplify: $9 - |8 - 4(7 - 5)|$.
Show a hint
Absolute value bars are a grouping symbol: simplify inside them first, then take the absolute value, then subtract.
Show the answers

  1. $16$

    $19 - |11 - 4(2)| = 19 - |3| = 19 - 3 = 16$.

  2. $9$

    $9 - |8 - 4(2)| = 9 - |0| = 9$.

Show the worked solution

The same steps as the video. Each ▶ button plays the part of the video where that step is explained.

Problem 1

$19 - |11 - 4(3 - 1)|$The problem. The bars group like parentheses, so start with the innermost parentheses.
$=$$19 - |11 - 4(2)|$$3 - 1 = 2$.
$=$$19 - |11 - 8|$Inside the bars, multiply before subtracting: $4 \cdot 2 = 8$.
$=$$19 - |3|$$11 - 8 = 3$.
$=$$19 - 3$The absolute value of $3$ is $3$.
$=$$16$Subtract.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$9 - |8 - 4(7 - 5)|$The problem. Start with the innermost parentheses.
$=$$9 - |8 - 4(2)|$$7 - 5 = 2$.
$=$$9 - |8 - 8|$Multiply before subtracting: $4 \cdot 2 = 8$.
$=$$9 - |0|$$8 - 8 = 0$.
$=$$9 - 0$The absolute value of $0$ is $0$.
$=$$9$
