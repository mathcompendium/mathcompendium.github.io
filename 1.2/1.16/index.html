  1. Simplify: ⓐ $21 - 13$ and $21 + (-13)$ ⓑ $-11 - 7$ and $-11 + (-7)$ ⓒ $6 - (-13)$ and $6 + 13$ ⓓ $-5 - (-1)$ and $-5 + 1$
  2. Simplify: ⓐ $15 - 7$ and $15 + (-7)$ ⓑ $-14 - 8$ and $-14 + (-8)$ ⓒ $4 - (-19)$ and $4 + 19$ ⓓ $-4 - (-7)$ and $-4 + 7$
Show a hint
Subtracting a number gives the same result as adding its opposite: $a - b = a + (-b)$.
Show the answers

  1. ⓐ $8$, $8$ ⓑ $-18$, $-18$ ⓒ $19$, $19$ ⓓ $-4$, $-4$

  2. ⓐ $8$, $8$ ⓑ $-22$, $-22$ ⓒ $23$, $23$ ⓓ $3$, $3$

Problem 1

$21 - 13$$=$$8$ⓐ
$21 + (-13)$$=$$8$The same answer: subtracting $13$ is the same as adding $-13$.
$-11 - 7$$=$$-18$ⓑ Taking $7$ more away from $-11$ goes further below zero.
$-11 + (-7)$$=$$-18$The same answer.
$6 - (-13)$$=$$19$ⓒ Taking away $-13$ is the same as adding $13$.
$6 + 13$$=$$19$The same answer.
$-5 - (-1)$$=$$-4$ⓓ Taking one negative from five negatives leaves four negatives.
$-5 + 1$$=$$-4$The same answer.
Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

$15 - 7$$=$$8$ⓐ
$15 + (-7)$$=$$8$The same answer: subtracting $7$ is adding $-7$.
$-14 - 8$$=$$-22$ⓑ
$-14 + (-8)$$=$$-22$The same answer.
$4 - (-19)$$=$$23$ⓒ Taking away $-19$ is the same as adding $19$.
$4 + 19$$=$$23$The same answer.
$-4 - (-7)$$=$$3$ⓓ
$-4 + 7$$=$$3$The same answer.
