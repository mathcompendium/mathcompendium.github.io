Try It 2.39

Your turn: problems like the one in the video
  1. Jesse has $\$6.55$ worth of quarters and nickels in his pocket. The number of nickels is five more than two times the number of quarters. How many nickels and how many quarters does Jesse have?
  2. Elane has $\$7.00$ total in dimes and nickels in her coin jar. The number of dimes that Elane has is seven less than three times the number of nickels. How many of each coin does Elane have?
Show a hint
Make a table of number, value and total value for each coin. Add the total values and set the sum equal to the total amount.
Show the answers

  1. Jesse has $41$ nickels and $18$ quarters.

  2. Elane has $22$ nickels and $59$ dimes.

The same steps as the video. Each ▶ button plays the part of the video where that step is explained.

Problem 1

Make a table. Quarters are worth $\$0.25$ and nickels $\$0.05$; the total value is $\$6.55$.
The nickels are described in terms of the quarters, so let $q$ = the number of quarters. Then $2q + 5$ = the number of nickels.
Number times value: the quarters are worth $0.25q$ and the nickels $0.05(2q + 5)$.
$0.25q + 0.05(2q + 5)$$=$$6.55$Add the total values and set the sum equal to the total.
$0.25q + 0.10q + 0.25$$=$$6.55$Distribute the $0.05$.
$0.35q + 0.25$$=$$6.55$Combine like terms.
$0.35q + 0.25 \hl{{} - 0.25}$$=$$6.55 \hl{{} - 0.25}$Subtract $0.25$ from both sides.
$0.35q$$=$$6.30$Simplify.
$\dfrac{0.35q}{\hl{0.35}}$$=$$\dfrac{6.30}{\hl{0.35}}$Divide both sides by $0.35$.
$q$$=$$18$Simplify. That's the number of quarters.
For the nickels, $2q + 5 = 2 \cdot 18 + 5 = 41$.
Jesse has $41$ nickels and $18$ quarters.

Check: $18(0.25) + 41(0.05) = 4.50 + 2.05 = 6.55$.

Problem 2

Try problem 2 again on your own first, using problem 1 as your guide. Then compare.

Make a table. Dimes are worth $\$0.10$ and nickels $\$0.05$; the total value is $\$7.00$.
The dimes are described in terms of the nickels, so let $n$ = the number of nickels. Then $3n - 7$ = the number of dimes.
Number times value: the nickels are worth $0.05n$ and the dimes $0.10(3n - 7)$.
$0.05n + 0.10(3n - 7)$$=$$7.00$Add the total values and set the sum equal to the total.
$0.05n + 0.30n - 0.70$$=$$7.00$Distribute the $0.10$. Careful: $0.10 \cdot (-7) = -0.70$.
$0.35n - 0.70$$=$$7.00$Combine like terms.
$0.35n - 0.70 \hl{{} + 0.70}$$=$$7.00 \hl{{} + 0.70}$Add $0.70$ to both sides.
$0.35n$$=$$7.70$Simplify.
$\dfrac{0.35n}{\hl{0.35}}$$=$$\dfrac{7.70}{\hl{0.35}}$Divide both sides by $0.35$.
$n$$=$$22$Simplify. That's the number of nickels.
For the dimes, $3n - 7 = 3 \cdot 22 - 7 = 59$.
Elane has $22$ nickels and $59$ dimes.

Check: $22(0.05) + 59(0.10) = 1.10 + 5.90 = 7.00$.
